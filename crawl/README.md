# 보험·부업 랜딩 데일리 크롤링

매일 오전 9시에 Claude Code 예약 작업("보험·부업 랜딩 데일리 크롤링")이 보험·부업 분야의 **DB 신청 랜딩을 새로 10개** 찾아 기록하고, 이 저장소에 올립니다.
기준과 방법은 첫 조사(`../reference-landings-crawl.md`, 2026-11-05)와 같습니다.

## 파일
- `daily/YYYY-MM-DD.md`: 그날 찾은 랜딩 10개 (한국 날짜 기준)
- `seen.txt`: 지금까지 기록한 랜딩·저장소 주소. 한 줄에 하나씩 적고, 여기 있는 주소는 다시 기록하지 않습니다.

## 찾는 대상
- **보험**: 설계사·FC 모집, 보장 점검·보험 상담, 보험 리모델링
- **부업**: N잡, 재택 부업, 투잡, 설계사 부업

## 판정 기준

| 조건 | 확정 | 추정 |
|---|---|---|
| ① DB 신청 (필수) | 이름·연락처 입력 + 개인정보 동의 + 접수 처리(폼 전송·시트·API)가 페이지에 있음 | — |
| ② Claude Code 사용 | GitHub 커밋에 `Co-Authored-By: Claude …` 서명 | 공개 저장소는 없지만 코드 주석·구조가 AI 코딩 도구 특유의 형태 |
| ③ 광고 사용 | 메타 광고 라이브러리에서 그 주소로 연결되는 광고, 또는 커밋에 "광고 랜딩", "메타용", "광고 심사" 등이 명시됨 | 광고 픽셀(메타·구글애즈·틱톡)·UTM 처리만 있음 |

| 등급 | 뜻 |
|---|---|
| **A** | ①②③ 모두 확정 |
| **B** | ①③ 확정 + ② 추정 |
| **C** | ① 확정 + ②③ 추정 (A·B로 10개를 못 채울 때만) |

## 조사 경로
1. **GitHub 커밋 검색**
   - Claude 서명과 함께 "보험", "설계사", "부업", "상담신청", "보장분석", "광고 랜딩", "메타 픽셀" 같은 키워드를 검색합니다.
   - 찾은 저장소의 배포 주소(GitHub Pages, Vercel, Netlify, 자체 도메인)도 확인합니다.
2. **웹 검색**: "설계사 모집 신청", "보험 부업 신청 30초", "재택 부업 상담 신청" 등
3. **메타 광고 라이브러리** (브라우저 도구가 연결돼 있을 때만)
   - 국가는 대한민국, 키워드는 "설계사 부업", "설계사 모집", "부업 첫 달", "보험 상담"
   - 광고에 연결된 주소를 모읍니다.
4. **각 페이지 확인**: HTML을 열어 ①③과 화면 구성을 확인합니다.

## 지키는 것
- 읽기만 합니다:
  - 신청서 제출, 개인정보 입력, 파일 내려받기는 하지 않습니다.
  - 로그인이 필요한 곳은 건너뜁니다.
- 찾지 못한 것을 지어내지 않습니다. 10개를 못 채우면 찾은 만큼만 쓰고 이유를 남깁니다.
- 자동 커밋은 `crawl/` 폴더만 대상으로 합니다.
