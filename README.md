# 메리츠파트너스 랜딩 작업실

Claude Code로 **메리츠파트너스 DB 신청(상담 신청서) 랜딩**을 만드는 공간입니다.
결과물은 매드업 개발팀이 그대로 퍼블리싱할 수 있는 **BC 캠페인 폴더** 형태로 나옵니다.

## 줄어든 절차

| 예전 | 지금 |
|---|---|
| 기획 → 디자인 시안(이미지) → 개발팀이 처음부터 다시 퍼블리싱 | 기획자가 Claude Code에 요청 → 매드업 구조 그대로인 BC 폴더 완성 → 개발팀은 폴더명·추적 코드만 넣고 배포 |
| AI로 만든 HTML을 넘기면 "구조가 안 맞아 다시 만들어야 한다"는 답이 옴 | 공통 파일(`assets/`, `main/`)은 건드리지 않고, 공통 함수·id·클래스를 그대로 써서 만듦 |

## 새 랜딩 만드는 법

1. **저장소 받기** (비공개 저장소라 초대받은 계정만 가능)
   ```bash
   git clone <저장소 주소>
   ```
2. **Claude Code에서 이 폴더 열기**: 데스크톱 앱 Code 탭에서 폴더를 선택하면, `CLAUDE.md`의 작업 규칙이 자동으로 적용됩니다.
3. **요청하기**: 아래 문구를 복사해서 캠페인에 맞게 바꿔 쓰면 됩니다.
   ```
   BC_MP_DRAFT를 참고해서 새 캠페인 폴더를 만들어줘. (폴더명: 개발팀이 준 캠페인 코드)
   랜딩 내용은 https://meritzpartners.com/BC○○○○○○/ 의 섹션을 모두 반영해줘.
   assets, main에 있는 규칙은 절대 변경하지 않고 따르며, 최우선적으로 참고해줘.
   ```
4. **미리보기**: 반드시 **8080 포트**로 엽니다. 다른 포트에서는 공통 스크립트가 **실제 메리츠 접수 서버**로 신청을 보냅니다.
   ```bash
   npx serve -l 8080 madup-meritz-src
   ```
   실행한 뒤 `http://localhost:8080/캠페인폴더/` 를 엽니다.
5. **개발팀 전달**: 캠페인 폴더를 zip으로 묶어 보냅니다. 폴더 안 `README.md`(개발팀 전달 메모)가 함께 들어가야 합니다.

## 폴더 구조

```
CLAUDE.md                     Claude Code 작업 규칙 (역할, 매드업 구조 규칙, 디자인 선호)
README.md                     이 문서
docs/작업기록-2026-11.md      이번 작업의 대화 정리 (결정 사항, 개발팀 피드백, 남은 일)
madup-meritz-src/
  assets/  main/              매드업 공통 파일. 절대 수정 금지 (영상 파일은 저장소에서 제외)
  BC261028/                   매드업이 준 참고 캠페인 (단계형 폼)
  BC_MP_DRAFT/                우리가 만든 캠페인 (한 페이지 설문형 폼). 새 랜딩의 출발점
BC_MP_DRAFT.zip               개발팀 전달용 압축본
mp-landing.html 등            매드업 구조 이전의 단일 파일 시안들 (참고용)
```

## 꼭 지킬 규칙

자세한 내용은 `CLAUDE.md`에 있고, 요약하면 다음과 같습니다.
- `madup-meritz-src/assets/`, `madup-meritz-src/main/`은 **수정·이동·삭제 금지**입니다. 새 랜딩은 BC 캠페인 폴더 하나에만 만듭니다.
- 단일 HTML 파일(이미지 내장, 자체 전송 코드)로 만들지 않습니다.
- 접수는 공통 `main.js`의 `save()`로만 합니다. `save()`가 읽는 id(`#user_name`, `#user_call`, `#user_sido`, `#user_gugun`, `#job_div_cd`, `#payment`, `#cns_req_hr_div_cd`, `#c_terms`, `#c_survey_privacy`)는 바꾸지 않습니다.
- 광고 추적 코드는 우리가 넣지 않고, 개발팀이 배포할 때 넣습니다.
- 사람 이미지와 사람 이모지는 쓰지 않습니다. 기존 캠페인 이미지를 복제하지 않습니다. 로고는 공식 파일만 씁니다.

## 저장소에 없는 것

- 매드업 원본의 영상 3개(약 155MB, `*.mp4` / `*.mov`)는 GitHub 용량 제한 때문에 뺐습니다. 랜딩 제작에는 쓰이지 않습니다. 필요하면 개발팀이 준 `메드업 메리츠 랜딩 샘플.zip`에서 꺼내 쓰면 됩니다.
