## 매드업 구조에서 알아낸 것

- 캠페인 폴더 구성: `index.html`, `images/`, `js/`, `style/style.css`
  - 캠페인 `style.css`는 손으로 쓴 파일이고, `.scss`에서 컴파일되지 않았어요.
- 공통 CSS 순서: `default` → `styles_08A` → `common_modal` → `modal_alert` → `./style/style.css` → `/main/css/footer.css`
- 공통 JS 순서: jquery·aos·swiper → axios → `commonScript` → `08/script` → `checkBadWords` → `form` → gsap → (캠페인 JS) → `main` → `loadHeader`
- **접수**: `main.js`의 `save()`가 고정 id에서 값을 읽어 `${API_URL}/meritz/consultation-information`으로 POST해요.
  - 읽는 id: `#user_name`, `#user_call`, `#user_sido`, `#user_gugun`, `#cns_req_hr_div_cd`(select), `#job_div_cd`, `#payment`, `#c_terms`, `#c_survey_privacy`, `#orgCd`
- **API 주소**: `localhost:8080` / `127.0.0.1:8080`일 때만 `http://localhost:8000`으로 보내고, 나머지 주소는 전부 운영 API로 보내요.
  → 로컬 미리보기는 반드시 8080 포트로 해야 해요.
- 공통 컴포넌트
  - 성공 시트: `#sheet-success.bottom-sheet` (`form.js`가 내용을 채움)
  - 안내창: `openLayerAlert()`
  - 이탈 방지: `.blockerModal` / `showblockerModal()`
  - 모달 틀: `.common-modal-wrap.modal-overlay`
- 마케팅 동의(`choAgrYn`)는 "활용 동의"와 "광고성 정보 수신"을 둘 다 동의했을 때만 Y예요 (BC261028 기준).
- 폴더명은 곧 랜딩 주소예요 (`meritzpartners.com/BC261028/`). 신청 데이터에 폴더명은 들어가지 않고, 매체 구분은 링크 뒤 값(`advtMdiaDivVal` 등)으로 해요.
